# 企业微信自动化助手 (WeCom Helper)

一款专为企业微信设计的自动化群发辅助工具，支持定时执行、自动唤醒屏幕，旨在提升企业微信群发任务的效率。

## 🌟 核心功能

*   **自动化群发**：自动识别群发助手页面，自下而上顺序点击发送，确保任务无遗漏。
*   **双执行模式**：
    *   **立即执行**：点击后立即开始任务。
    *   **定时执行**：自定义运行时间区间（支持跨天，如 23:00 - 01:00），到点自动开始，过期自动停止。
*   **智能唤醒**：内置后台心跳检查（每2分钟一次），在设定的时间内自动点亮屏幕并拉起企业微信。
*   **内存优化**：精细的无障碍节点回收机制，长时间运行不卡顿、不闪退。
*   **现代 UI**：基于 Jetpack Compose 构建的 Material 3 风格界面，简洁美观。

## 🚀 安装与设置

### 1. 下载安装
从 [Releases](https://github.com/Jarvizzh/wecom-helper/releases) 页面下载最新的 APK 文件并安装。

### 2. 权限开启 (至关重要)
由于 Android 系统限制，尤其是 **MIUI (小米/红米)** 用户，请务必手动完成以下设置：

*   **无障碍服务**：`设置` -> `更多设置` -> `无障碍` -> `已下载的服务` -> 开启 `企业微信助手`。
*   **自启动**：在应用信息页开启 `自启动`。
*   **省电策略**：在应用信息页将 `省电策略` 设置为 **“无限制”**。
*   **锁屏显示** (MIUI 特有)：`权限管理` -> 开启 **“锁屏显示”**。
*   **后台弹出界面**：`权限管理` -> 开启 **“后台弹出界面”**。

### 3. 使用步骤
1.  打开 App，点击“开启辅助权限”。
2.  点击“开始群发任务”，在弹出的面板中选择模式。
3.  配置时间区间及是否“自动唤醒”。
4.  点击“立即开启自动化”，App 将自动跳转至企业微信。

## 🛠️ 技术实现

*   **开发语言**：Kotlin
*   **UI 框架**：Jetpack Compose (Material 3)
*   **核心技术**：Android AccessibilityService, Coroutines (Flow/Ticker), PowerManager (WakeLock)

## ⚠️ 注意事项

*   **安全性**：本工具仅通过模拟点击实现自动化，不涉及任何协议破解，请合规使用。
*   **锁屏密码**：自动唤醒功能无法绕过数字/图形锁屏密码。建议使用时取消锁屏密码或设置为“轻扫解锁”。
*   **企业微信版本**：建议使用最新版企业微信以获得最佳兼容性。
